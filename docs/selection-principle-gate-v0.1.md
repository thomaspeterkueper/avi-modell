# AVI — Selection-Principle Gate v0.1

**Stand:** 27. September 2026  
**Status:** kritisches Theorie-Gate nach Operator Minimality Gate  
**Pfad:** O1-minimal / Class B

## 1. Gate-Frage

Lässt sich aus den bereits vorhandenen AVI-Grundannahmen — ohne Auswahl nach beobachteten Anomalien — eine Symmetrie, Invarianz, Erhaltungsstruktur oder andere mathematische Bedingung ableiten, die den generischen EFT-Operatorvektor

    c_a = λ n_a

nichttrivial einschränkt?

Nur dann besitzt O1 eine Chance auf eine AVI-spezifische lokale Vorhersage.

## 2. Zulässige Ausgangsprinzipien

Dieses Gate verwendet ausschließlich bereits dokumentierte AVI-Struktur:

1. **Relationalität:** bevorzugte Observablen sind dimensionslose Verhältnisse.
2. **Differentialität:** ein rein universeller common-mode lokaler Faktor fällt aus lokalen Ratenverhältnissen heraus.
3. **State completeness:** Standardzustand Y und Kanalzustand C müssen vollständig beziehungsweise probabilistisch marginalisiert sein, bevor ξ eingeführt wird.
4. **Historien-/Zusatzstatus:** ξ darf nur zusätzliche physikalische Zustandsinformation darstellen, nicht eine Umbenennung rekonstruierbarer Standardhistorie.
5. **Nullfall:** bei verschwindender AVI-Kopplung muss QFT+GR exakt zurückgewonnen werden.
6. **Class-B-Scope:** im führenden Arbeitsregime soll die Standard-Hintergrundexpansion unverändert bleiben.
7. **Sparsamkeit:** keine unabhängigen freien Kopplungen pro Messkanal.
8. **Präregistrierung:** Treiber, Signaturrichtung und Kopplungsstruktur müssen vor dem Ziel-Datenfit feststehen.

Philosophische Motive aus der Omnizedenz sind keine physikalischen Axiome und werden nicht zur Operatorauswahl verwendet.

## 3. Kandidat P1 — Dimensionslosigkeitsprinzip

AVI bevorzugt dimensionslose Observablen und normierte Zustandsgrößen.

### Ableitungskraft

Dies schließt dimensionsbehaftete Zwischenvariablen nicht aus. EFT-Operatoren können mit einer Skala Λ dimensionslos normiert werden.

Daher folgt aus Dimensionslosigkeit nicht

    n_a = unique.

**Ergebnis: methodische Konsistenzregel, keine Operatorselektion.**

## 4. Kandidat P2 — Relationalitätsprinzip

Die Observable soll als Verhältnis Γ_i/Γ_j oder gegenüber einer unabhängigen Referenz formuliert werden.

### Ableitungskraft

Relationalität eliminiert unmessbare Einheitenkonventionen und kann common-mode Beiträge entfernen.

Sie bestimmt aber nicht, welcher fundamentale Sektor ξ koppelt. Viele verschiedene Operatorvektoren erzeugen relationale Observablen.

**Ergebnis: Observable-Selektion, keine fundamentale Operatorselektion.**

## 5. Kandidat P3 — Differentialitätsprinzip

Für lokale Ratenverhältnisse muss

    S_i · n != S_j · n

für mindestens ein geeignetes Paar gelten.

### Ableitungskraft

Dies schließt den exakt universellen common-mode-Vektor für diese Observable aus.

Es verbleibt jedoch ein hochdimensionaler Unterraum zulässiger n_a.

**Ergebnis: schwacher Ausschluss, keine eindeutige Richtung.**

## 6. Kandidat P4 — Historien-/ξ-Prinzip

ξ trägt unabhängige Zustandsinformation und soll nicht aus dem momentanen Standardzustand rekonstruierbar sein.

### Ableitungskraft

Dies beschränkt die Ontologie und Dynamik von ξ, nicht automatisch seinen Kopplungsoperator.

Aus

    ξ_A != ξ_B

folgt keine eindeutige Aussage darüber, ob ξ an elektromagnetische, Yukawa-, QCD-, schwache oder gravitative Operatoren koppelt.

**Ergebnis: Zustandsselektion, keine Operatorselektion.**

## 7. Kandidat P5 — Class-B-Prinzip

Im engen Arbeitsregime:

    H = H_std

bis zu einer festzulegenden Genauigkeit.

### Ableitungskraft

Dies benachteiligt Operatoren beziehungsweise Parameterbereiche mit großer gravitativer Backreaction und kann rein gravitative Kopplungen besonders stark einschränken.

Aber auch elektromagnetische, fermionische oder QCD-Kopplungen können in geeigneten schwachen Regimen Class B approximieren.

**Ergebnis: wichtiger Filter, aber keine eindeutige n_a-Richtung.**

## 8. Kandidat P6 — Minimalität/Sparsamkeit

AVI verlangt einen gemeinsamen Parameter λ und eine präregistrierte Richtung n_a.

### Ableitungskraft

Sparsamkeit sagt, **dass** n_a festgelegt werden muss, nicht **welcher** n_a physikalisch gilt.

Eine mathematisch einfache Wahl wie

    n_a proportional to (1,1,...)

wäre ohne zusätzliche Symmetrie nur eine Konvention.

**Ergebnis: Modellselektionsregel, keine Naturgesetzableitung.**

## 9. Kandidat P7 — universelle ξ-Kopplung

Eine mögliche stärkere Annahme wäre, ξ müsse aufgrund seines globalen Charakters universell an alle Sektoren koppeln.

### Prüfung

Diese Aussage folgt aus keinem bisherigen AVI-Axiom.

Zudem würde eine exakt universelle Skalierung in rein lokalen dimensionslosen Ratenverhältnissen weitgehend common-mode werden. Nichtuniverselle Restwirkungen benötigten erneut eine Sektorstruktur.

**Ergebnis: nicht ableitbar; wird nicht als AVI-Prinzip eingeführt.**

## 10. Kandidat P8 — Kopplung an Spur/Skalenstruktur

Eine theoretisch attraktive Möglichkeit wäre eine Kopplung an eine universelle Skalen- oder Spurstruktur, etwa schematisch an dimensionslose Antworten auf Skalentransformationen.

### Prüfung

Dies könnte verschiedene Sektoren über eine gemeinsame mathematische Struktur verbinden und n_a stärker einschränken.

Aber: Eine solche Regel ist **nicht** aus den bisherigen AVI-Axiomen hergeleitet. Sie wäre ein neues physikalisches Postulat und müsste gegen bekannte dilaton-/scalar-tensor-/trace-coupling-Strukturen abgegrenzt werden.

**Ergebnis: interessanter Forschungszweig, aber kein Ergebnis dieses Gates.**

## 11. Kandidat P9 — Kopplung ausschließlich an kosmologische Referenzgrößen

Die ursprüngliche AVI-Intuition könnte nahelegen:

    ξ/global state -> local rate relative to cosmological reference.

### Prüfung

Dies spezifiziert die Referenzseite, nicht den lokalen Operator, durch den eine atomare, molekulare oder nukleare Rate reagieren soll.

Ohne lokale Wechselwirkung bleibt keine berechenbare Response.

**Ergebnis: konzeptionelle Architektur, keine Operatorselektion.**

## 12. Gesamtresultat

Keines der bereits vorhandenen AVI-Prinzipien bestimmt derzeit einen eindeutigen oder ausreichend engen Operatorvektor n_a.

Die Prinzipien leisten dennoch reale Arbeit:

- State completeness verhindert falsche ξ-Zuschreibungen;
- Differentialität entfernt common-mode Nullrichtungen;
- Class B begrenzt Backreaction;
- Relationalität bestimmt robuste Observabletypen;
- Sparsamkeit verbietet kanalweise freie Fits;
- Präregistrierung verhindert Anomalie-getriebene Operatorwahl.

Aber diese Regeln definieren bislang einen **zulässigen Raum**, keine spezifische fundamentale Richtung innerhalb dieses Raums.

## 13. Gate-Ergebnis

**Selection-Principle Gate: FAIL FOR UNIQUE AVI OPERATOR SELECTION.**

Das ist ein harter, produktiver negativer Befund.

O1 ist damit in seinem derzeitigen Zustand:

    AVI-motivated question
      + generic extra degree of freedom
      + generic EFT coupling constraints,

aber noch keine eigenständige mikrophysikalische Theorie.

Es wäre methodisch falsch, jetzt n_a frei auszuwählen und anschließend als AVI-Vorhersage zu behandeln.

## 14. Was aus AVI dennoch eigenständig bleibt

Das negative Gate bedeutet nicht, dass die gesamte Forschungsfrage redundant ist.

Eigenständig und weiter prüfbar bleiben insbesondere:

1. die scharfe Frage nach gleicher vollständiger Gegenwart bei verschiedener zusätzlicher Zustandsinformation;
2. die Trennung von ontischem Zustand, Rekonstruktionsunsicherheit und Kanalzustand;
3. die Forderung nach relationalen, differentiellen, kanalübergreifenden Tests;
4. die explizite Möglichkeit, dass kein zusätzlicher Zustand benötigt wird.

Dies ist derzeit stärker als **Test- und Modellierungsarchitektur** als als neue fundamentale Dynamik.

## 15. Entscheidung über O1

O1 wird nicht verworfen, aber als aktiver mikrophysikalischer AVI-Zweig auf **HOLD** gesetzt.

Reaktivierung erfordert mindestens eines von:

- eine unabhängig motivierte Symmetrie, die n_a einschränkt;
- eine konkrete fundamentale AVI-Dynamik, aus der n_a folgt;
- einen theoretischen Konsistenzsatz, der nur eine kleine Operatorfamilie zulässt.

Ein empirisches Residuum allein genügt ausdrücklich nicht.

## 16. Neuer nächster Grundlagenpfad

Nach O2-HOLD und O1-HOLD sollte AVI nicht durch weitere Freiheitsgrade erweitert werden.

Der nächste sinnvolle Schritt ist ein **Core Invariant Reconstruction Gate**:

> Welche Aussagen von AVI bleiben erhalten, wenn ξ, Φ und jede konkrete Kopplung zunächst entfernt werden?

Ziel ist, den minimalen theoretischen Kern als Menge von Invarianz-, Zustands- und Falsifikationsaussagen neu zu formulieren.

Erst danach darf entschieden werden, ob

- daraus eine neue Dynamik ableitbar ist,
- AVI primär ein Meta-/Testframework für Historieninformation bleibt,
- oder ein Teil der bisherigen Modellstruktur aufgegeben werden sollte.
