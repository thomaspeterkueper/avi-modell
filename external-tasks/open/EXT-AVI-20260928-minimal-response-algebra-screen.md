# Request: MRA-1 Minimal Response Algebra Construction Screen

## Priorität
NEXT CORE GATE nach AVI-R1.

## Ziel
Prüfen, ob eine mathematisch sparsame Response-Algebra eine unabhängig definierte relationale/globale Zustandsstruktur auf mehrere lokale dimensionslose Observablen abbilden kann und dabei strengere Vorhersagen als generische EFT erzeugt.

## Kontrollklassen
1. lineare Response-/Suszeptibilitätsmatrizen;
2. low-rank / constrained response;
3. symmetry- und representation-basierte Selektionsregeln;
4. relational/conditional-state maps;
5. kausal unterstützte nonlocal kernels.

## Pflichtprüfungen
- QFT+GR equivalence/reduction;
- local-EFT/Wilson-coefficient reduction;
- rank/parameter count;
- null-space existence;
- mindestens eine feste cross-observable ratio/relation;
- covariance/operational definition;
- causality/no-signalling;
- backreaction/conservation;
- Markov embedding;
- keine Kalibrierung an aktuelle Anomalien.

## PASS
Mindestens eine Klasse liefert eine wohldefinierte, AVI-kompatible Struktur mit weniger Freiheitsgraden als generische EFT sowie präregistrierbarer Nullrichtung und cross-observable Relation.

## HOLD
Mathematisch plausible Struktur, aber G_rel oder physikalische Implementierung nicht unabhängig definiert.

## FAIL
Alle Kandidaten reduzieren sich auf Standard-QFT+GR oder generische EFT bzw. benötigen ebenso viele freie Kopplungen.
