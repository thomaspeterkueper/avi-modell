# Request: CB-1E Independent Dataset Matrix

## Ziel
Erstelle eine Evidenzmatrix für CMB-Birefringenz, die methodische von echter Datenunabhängigkeit trennt.

## Scope
Planck PR4/NPIPE, ACT DR6, relevante WMAP/SPTpol/POLARBEAR/BICEP-Constraints sowie kommende unabhängige Polarisationsmessungen.

## Anforderungen
Für jeden Datensatz: Frequenzen, Himmelsanteil, Observable, β/Constraint, Kalibrationsmethode, foreground treatment, gemeinsame Inputs/Systematiken, Publikationsstatus. Keine Signifikanzen kombinieren, solange Korrelationen nicht explizit modelliert sind.

## Akzeptanz
Maschinenlesbare oder tabellarische Matrix plus Regeln für spätere AVI-Likelihood-Nutzung.
