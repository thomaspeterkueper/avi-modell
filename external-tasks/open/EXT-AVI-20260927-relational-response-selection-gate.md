# Request: AVI-R1 Relational Response Selection Gate

## Priorität
NEXT CORE GATE nach Operator Minimality Selection Rule v0.1.

## Leitfrage
Kann eine globale/relationale AVI-Zustandsstruktur eine lokale dimensionslose Response erzeugen, ohne vollständig in QFT+GR aufzugehen oder zu einer generischen lokalen EFT mit frei wählbaren Kopplungen zu werden?

## Arbeitsprogramm
1. Minimalen relationalen state space definieren, ohne Spin/Feldcharakter vorwegzunehmen.
2. Kandidaten für eine Response map R: G_global -> Q_local -> O_i klassifizieren.
3. Markov-Embedding-Test: prüfen, ob die vermeintliche Historieninformation nur durch zusätzliche Standardzustände lokalisierbar ist.
4. QFT-completeness-Test: bekannte boundary/state/correlation responses als Nullmodell abziehen.
5. EFT-reduction-Test: prüfen, ob R äquivalent zu lokalen Operatoren mit freien g_i ist.
6. Causality-/no-signalling-Vertrag formulieren.
7. Backreaction/Energie-Buchhaltung explizit machen.
8. Parameterzählung gegen generische EFT durchführen.
9. Mindestens eine präregistrierte Nullvorhersage und eine cross-observable Relation verlangen.

## PASS
Nur wenn eine konstruktive Response weniger Freiheitsgrade als generische EFT besitzt und mindestens eine neue falsifizierbare Relation liefert.

## HOLD
Wenn eine konsistente relationale Architektur existiert, aber keine eindeutige lokale Response.

## FAIL
Wenn jede zulässige Realisierung entweder QFT+GR-nullmodelläquivalent oder generische EFT ist.
